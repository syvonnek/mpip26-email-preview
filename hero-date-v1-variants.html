Date lockup — four takes

Same Option 1 skeleton, smaller date throughout, and the gradient conflict resolved a different way in each. International strip unchanged from the last study, omitted here to keep the eye on the lockup. On the time question: my take is drop it from the hero — it is a detail, it is already in the program section, and Zoom converts it anyway. Variant D shows the keep-it version so you can compare.

A — Solid white date, gradient subtitle stays

The date drops to 30px solid white. The subtitle keeps the spectrum gradient as the hero's only gradient text, so nothing competes: gradient = what it is, white = when. No time.
